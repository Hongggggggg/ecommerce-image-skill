# 信息补全与宣称规则

## 事实分类

接收商品图片和介绍后，先在对话中整理四类信息：

1. 已确认事实：用户明确提供，或可从清晰图片中可靠识别。
2. 缺失信息：会影响构图、文案、尺寸或合规，但当前无法确定。
3. 创意选择：可以由 Agent 推荐，但必须由用户确认。
4. 禁止推断：尺寸、重量、销售数量、包装内容、材质、认证、性能等级、适用年龄和治疗效果等。

事实分类回答“输入是什么、是否已知”；下述声明台账回答“面向消费者的具体表述能否使用”。两层必须同时保留，不能把用户提供过或图片中可见的信息自动等同于可发布宣称。

## 声明与证据四态台账

在编写客户可见文案或把事实转化为视觉结论前，先建立声明与证据台账。每条客户可见商品名称、事实、数字、数量、材质、兼容、性能、比较、认证、效果或包装内容表述都必须绑定一个内部 `claim_id`；通用商品名称可以绑定商品身份项，不必另造营销证据：

| claim_id | 拟用表述 | 状态 | 证据/来源 | 适用条件 | 限定词或免责声明 | 风险与动作 |
|---|---|---|---|---|---|---|
| C01 | ... | VERIFIED / CONDITIONAL / PLACEHOLDER / BLOCKED | ... | ... | ... | ... |

四种状态的含义和处理固定如下：

- `VERIFIED`：证据足以支持该表述；只能在证据覆盖的对象、数值、单位、条件和范围内使用。
- `CONDITIONAL`：只有加入准确限定词、可读免责声明或完成指定品类/平台复核后才可使用。任一条件未满足时不得进入生成；所需限定文字无法在移动端清楚容纳时，删除该声明或将其改为 `BLOCKED`，不能缩成不可读小字。
- `PLACEHOLDER`：缺少真实值，仅可在非像素策划中用 `[NEEDS INPUT: ...]` 记录。禁止进入 `allowed_text_exact`、图像模型提示、图片像素或发布候选；可删除该表述或改用不依赖缺失值的安全主题继续。
- `BLOCKED`：证据不足、误导、被平台禁止或与商品矛盾。禁止进入文案、提示词、视觉暗示和成图。

`claim_id`、状态名、证据来源和风险动作只属于内部非像素记录，默认不得出现在图片中，也不得为了展示追溯关系加入 `allowed_text_exact`。每条最终逐字文案必须能反查唯一或明确的一组 `claim_id`；同一 claim 支撑多处文字时仍复用原 ID，不为每张图重复发明事实。

数字、性能、认证、测试、比较或高风险声明的证据至少记录来源主体、资料名称或文件、日期/年份、测试或适用条件，以及必须保留的单位、限定词和免责声明；资料没有提供的字段写 `UNKNOWN`，不得补猜。目标平台另有高风险或品类规则时，继续读取对应平台分支。

## 提问原则

- 每轮集中询问 1～3 个问题。
- 优先问会阻塞下一步的问题。
- 给出 2～3 个适合当前商品的选项，并说明推荐项。
- 不再询问已经可以可靠识别的信息。
- 用户暂时无法回答时，给出安全替代方案，让流程可以继续。

## 开始前向用户展示的资料模板

使用本 Skill 前，先用简短表单提示用户尽量提供以下内容。用户不必重复清晰图片中可可靠识别的信息；缺少非阻塞项时由 Agent 给出安全降级方案。

```text
产品名称/品类：
核心卖点及依据：
适用人群：
期望使用场景：
具体参数与单位：
包装内容/数量/变体：
目标市场与平台：
图片语言及地区版本：
首图类型（平台干净主图 / 营销首图 / 两者都要）：
希望包含的图片类型、数量与优先级：
品牌色、Logo、参考图与禁止元素：
```

用户没有指定图片类型时，不把整个类型列表当成阻塞问卷。先完成事实卡，再根据商品形态、购买疑虑、证据和平台规则推荐 7～9 张，列出“建议保留、按证据可选、不建议/资料不足”，请用户一次确认。

建议优先级：

1. 商品身份与销售变体。
2. 目标国家或区域与平台。
3. 图片文案语言、地区版本及双语层级。
4. 包装内实际包含内容。
5. 尺寸、重量与单位。
6. 材质、目标人群与场景。
7. 卖点证据与敏感宣称。
8. 品牌资产和准确文字。
9. 与目标区域契合的视觉风格。

## 区域与语言确认

区域、平台和图片文案语言是强制确认项，不得从项目背景或用户使用的沟通语言直接推断。

当用户只上传商品图并要求制作套图时，第一轮必须分别询问以下三题，不得合并，也不得插入其他补充问题：

1. 商品主要面向哪个国家或区域、哪个平台？
2. 图片内使用中文、英文、双语还是无文字？英文使用美式、英式还是其他地区版本？
3. 采用哪种视觉风格？给出 2～3 个与当前商品、区域、平台和人群相符的方向。

每题标明推荐项并简述理由，但推荐不构成确认。只有用户逐项选择，或在看见三题的推荐项后明确回复“全部按推荐”，才算完成确认。确认后回显区域与平台、语言版本、视觉风格三项摘要。当地人群、文化、节日、场景与视觉偏好等细节放到后续信息补全轮次。

## 宣称规则

以下内容必须有用户提供的证据或明确确认，不能仅凭外观推断：

- 防水、防火、防摔、承重、耐高温、抗菌等性能。
- 食品级、医用级、无毒、环保、有机等属性。
- FDA、FCC、CE、UL 等认证或合规声明。
- 治疗、缓解、修复、减肥、改善疾病等健康效果。
- “最强”“第一”“100% 有效”等绝对化表述。

处理顺序：

1. 请用户提供事实、测试、证书或可核验依据。
2. 为拟用表述分配 `claim_id`，按证据完整度标记 `VERIFIED`、`CONDITIONAL`、`PLACEHOLDER` 或 `BLOCKED`。
3. 有依据时，将可用范围、准确措辞、限定条件和证据来源写入台账；不得把原始证据的强度放大。
4. 无依据时删除该卖点，或提出不承诺效果的中性表达并请求确认；原表述标为 `BLOCKED`。
5. 只有 `VERIFIED`，或已经满足全部限定条件的 `CONDITIONAL` 表述才能进入图片。

## 缺失信息的安全降级

- 缺尺寸：不做尺寸图，改为细节、步骤或包装内容图。
- 包装内容不明：不展示数量和配件，先确认。
- 材质不明：不写具体材质名，仅描述可见结构；如“textured surface”。
- 适用人群不明：使用通用场景，避免年龄、身份或医疗暗示。
- Logo 或包装文字不清：不自行重构；请用户上传清晰素材，或使用不突出文字的构图。
- 卖点证据不足：删除或换成中性表达。
- 声明仍为 `PLACEHOLDER`：不得把占位符带入图像提示；删除该文字或换成不依赖该缺失值的图片任务。

## 对话中的商品事实卡

事实卡应清晰列出：

- 商品名称、品类和销售变体。
- 目标国家或区域、平台和目标人群。
- 图片文案语言、地区版本和双语层级。
- 每张源图的用途。
- 颜色、材质、结构和不可改变项。
- 尺寸、重量、数量和单位。
- 目标用户和使用场景。
- `shopper_job`：顾客希望借助该商品完成的具体任务。
- 主要购买异议：顾客在下单前最可能需要消除的疑虑。
- 信息不确定性：资料或视觉尚不能可靠回答的问题。
- 退货风险驱动因素：尺寸、兼容、数量、材质、使用方式或预期差异等可能导致退货的因素。
- 已确认卖点及依据。
- 声明与证据四态台账。
- 品牌资产与必须准确呈现的文字。
- 禁止出现或禁止改变的元素。
- 尚待用户确认的事项。

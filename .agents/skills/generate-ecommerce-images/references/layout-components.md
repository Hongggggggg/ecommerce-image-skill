# 可选版式组件

本文件定义可叠加到 15 个核心框架上的局部信息组件。框架决定大结构和阅读顺序；组件只解决局部证据、状态、尺寸、步骤或免责声明，不是新的框架，也不是每张图的必选项。

## 目录

- 使用预算与选择流程

## 使用预算与选择流程

每张非平台营销图先写：

```text
组件：NONE
信息缺口：无
```

只有存在明确的信息缺口时才改用组件：

1. 说明组件解决什么信息缺口。
2. 写明组件 ID、区域、面积、内容和与商品的连接关系。
3. 确认组件不会成为第一焦点，不会重复标题，也不会遮挡商品结构。
4. 在 180～240 px 检查它是否仍有意义；若只能看到装饰形状，删除。

套图预算：

- Amazon MAIN、TikTok Shop 干净首图等平台要求无营销元素的合规主图一律为 `NONE`，不计入组件使用预算。
- 营销首图/商品封面允许 `0..1` 个 C01～C08 组件。组件可承载卖点标签、详细说明、真实局部、规格、状态或必要免责声明，但必须与主商品中的核心证据直接相连；没有信息增量时仍写 `NONE`。
- 组件预算按最终成图实际形态统计，不按策划 ID 或提示词统计。模型擅自生成的圆窗、卡片、芯片、标签、徽章、胶囊、微步骤条和独立图标信息块均计入；`组件：NONE` 表示成图实际组件数必须为 0。
- 营销首图单图组件数为 `0..1`，其他营销图为 `0..2`；超过对应预算直接返工。使用组件时必须解决从属于同一主任务的信息缺口，不能只是装饰叠加。
- 7/8/9 张套图中，出现任何 C01～C08 的图片数上限分别为 4/5/6；平台干净主图固定 `NONE`。
- 每套至少保留 2 张 `component=NONE` 且 `evidence_dominant=true` 的营销图，让摄影、场景、材质或商品结构主导画面；这些图片仍可使用直接标注的 `label/detail`，平台干净主图不计入这 2 张配额。
- `组件：NONE` 不等于 `文字：NONE`。功能使用场景必须有一组直接贴近动作、接触、适配或摆放证据的 `label + detail`，同时可以保持组件为 `NONE`；主画布还必须显示动作和接触/摆放点，不能把动作藏在组件内。文字配额只按 [套图蓝图](image-set-blueprints.md) 判断。
- 所有非平台合规图的证据文案均可使用 [转化设计系统](conversion-design-system.md) 定义的 `label`、`detail` 或两者组合；营销首图另有一条必填价值说明 `subtitle`。说明可以直接沿商品轮廓、引线或结构节点排布，不要求先放进卡片；组件内外均须贴近证据、避开商品关键部位并保持移动端可读。
- `label + detail` 是营销首图、卖点图、细节图和材质图的默认最低证据文案对，但不是“必须装进卡片”的组件配方。场景、尺寸、步骤、包装、兼容和状态图也可按信息增量使用。是否采用卡片、采用几个组件以及如何摆放，必须由信息缺口、真实证据和构图空间决定；不得让所有图片重复相同卡片位置、尺寸和层级。
- 单张小卡片占画布 7%～14%；同图全部卡片合计不得超过 22%。
- 圆形细节窗直径占画布 16%～28%；超出范围必须记录角色必要性，否则返工。
- 1024×1024 后续营销图中的组件文字遵守 [转化设计系统](conversion-design-system.md) 字号基线：状态、步骤和尺寸标签通常为 34～48 px，最低 32 px；免责声明通常为 28～36 px，最低 26 px。标签字形包围盒保留至少 28 px 内边距，含 padding 后距画布边缘至少 5.5%。达不到时放大组件、缩短文案或删除组件，不保留不可读小字，也不得削减 padding 硬塞。
- 连续两张在同一位置使用同一组件的次数必须为 0；同套图中同一组件 ID 最多出现 2 次。
- `DESIGN PREVIEW`、`SIMULATED`、`NOT PUBLISHABLE`、`SIMULATED DIMENSIONS` 等状态文字默认不得进入成图，因此不能用它们制造组件或套图节奏变化；只有用户明确批准可见披露时才按 `disclosure` 记录，仍不计为 C01 证据卡或商品信息。

## C01 证据小卡

- **任务**：把一个已由画面证明的卖点压缩成短结论。
- **内容**：若 C01 承担本图唯一的卖点/细节/材质证据，使用一个 2～5 个英文词的 `label` 配一条 4～10 个英文词的 `detail`；本图其他位置已有完整证据对时，C01 可只保留其中之一。文案必须遵守 [转化设计系统](conversion-design-system.md) 的证据事实规则。
- **结构**：圆角矩形、低对比底色、明显内边距；可包含真实局部小图，但不得只放装饰图标。
- **适合**：H01、H04、P04、L02。
- **不适合**：合规首图、已有大标题和两个证据窗的拥挤画面。
- **约束**：面积 8%～14%；不重复主标题；不形成三卡并排的默认模板；禁止用 `Soft & Comfortable`、`Fine Craftsmanship`、`Solid Materials` 等无证据形容词填卡。

## C02 圆形细节窗

- **任务**：用大小景别反差证明一个真实局部。
- **内容**：真实微距图，可配 1 个短标签。
- **结构**：圆形或近圆形裁切，通过细线、节点或重叠关系连接到商品准确部位。
- **适合**：H01、H03、P01、D02。
- **不适合**：没有清晰细节源图、步骤图、纯场景图。
- **约束**：直径 16%～28%；不得使用无对应部位的任意纹理；每图通常只用 1 个。

## C03 照片证据卡

- **任务**：在主商品之外展示一个独立但从属的使用、状态或材质证据。
- **内容**：真实局部或第二视角照片＋短标签。
- **结构**：带明确边界和接触阴影的小卡，可与主商品轻叠，但不可看成第二个销售单位。
- **适合**：H04、P02、P03、L03。
- **不适合**：多件套包装清单、数量容易误解的单品。
- **约束**：面积 10%～18%；必须标明“DETAIL”“SAME ITEM”或状态关系之一。

## C04 规格芯片

- **任务**：突出一个准确尺寸、数量、兼容范围或规格。
- **内容**：一个数字＋单位，或一个短兼容标签。
- **结构**：紧凑胶囊或小矩形，与尺寸线、接口或对应端点绑定。
- **适合**：D01、D02、P04、S02。
- **不适合**：没有事实依据、数字不需要突出时。
- **约束**：只显示已确认数据；不能用大数字冒充主标题；同图通常不超过 3 个且必须共同解决一个任务。

## C05 状态标签

- **任务**：帮助用户区分同一商品的两个状态、视角或步骤。
- **内容**：`OPEN / CLOSED`、`FLAT / ASSEMBLED`、`BEFORE / AFTER` 等已确认状态词。
- **结构**：小型标签、页签或上下文色块，位置在对应状态附近且高度一致。
- **适合**：P03、P02、S01、D01。
- **不适合**：只有一个状态或会引入虚假比较时。
- **约束**：标签不是证据本身；两侧视角、尺度和光线仍需一致。

## C06 免责声明胶囊

- **任务**：避免道具、场景物或重复视图造成包装内容和数量误解。
- **内容**：`STYLING PROPS NOT INCLUDED`、`SAME ITEM • TWO VIEWS` 等必要说明。
- **结构**：低权重小胶囊，位于安全边距内，不做全宽底栏。
- **适合**：P03、P04、L02、D01、S01。
- **不适合**：可以通过删掉误导元素解决的画面；合规首图。
- **约束**：只在确有歧义时使用；移动端不可读时仍不得成为唯一消歧手段。

## C07 材质样本卡

- **任务**：展示已确认材质、纹理、织法、表面或层次。
- **内容**：真实材质微距＋准确材质名或中性可见描述。
- **结构**：方形或竖向小卡，边缘可使用材质本身的形状；与商品局部保持颜色和光线一致。
- **适合**：H03、P01、L02。
- **不适合**：材质未知、表面没有可见价值、容易与 C02 重复时。
- **约束**：不得用生成纹理代替真实证据；若已有 C02，通常二选一。

## C08 微步骤卡

- **任务**：补充一个主画面中的 2～3 个简短连续动作。
- **内容**：编号、短动作标签和连续状态小图。
- **结构**：小型横向或纵向步骤条，始终从属于主商品。
- **适合**：H04、L03、S01。
- **不适合**：完整步骤图已经是主结构；超过 3 步；会造成数量误解。
- **约束**：总面积不超过 20%；每步必须有不同动作状态，不能复制同一商品照只换编号。

## 框架兼容与套图节奏

| 框架 | 优先组件 | 通常保持 NONE 的情况 |
|---|---|---|
| H01 | C02、C01 | 商品轮廓或动作本身已足够强 |
| H02 | C05 | 动作路径已清楚，不再加卡片 |
| H03 | C02、C07 | 主微距已占足够画面时 |
| H04 | C01、C03 | 场景关系本身可直接说明用途 |
| P01 | C02、C07 | 连接点已经清楚且有准确标签 |
| P02 | C03、C05 | 结构展开已复杂 |
| P03 | C05、C06 | 两侧状态一眼可辨且无数量歧义 |
| P04 | C01、C04、C06 | 容纳关系无需数字或免责声明 |
| L01 | C01 | 人体动作已经完整证明使用 |
| L02 | C01、C06、C07 | 纯编辑式场景图 |
| L03 | C03、C08 | 第一视角动作已经足够清楚 |
| D01 | C04、C05、C06 | 尺寸线和数字已完整 |
| D02 | C02、C04 | 接口关系已经清楚 |
| S01 | C05、C06 | 完整步骤图，不再嵌套 C08 |
| S02 | C04、C06 | 组件和数量已由主网格完整表达 |

推荐套图节奏示例：

```text
平台干净首图：NONE
营销首图：NONE 或 1 个与核心证据相连的 C01～C08
状态图：C05 + C06
功能使用场景：NONE（必须有一条直接证据说明）
细节图：C07
尺寸图：C04
第二场景：NONE
步骤图：C05
```

这只是节奏示例，不是默认模板。真实套图应根据商品证据删减。

H03 默认不参与营销首图竞争。H04 用于营销首图时，主证据区应为与画面边缘相连的大尺度分区，并由主商品自身的动作、结构或场景关系建立证据；允许的一个小圆窗、卡片或胶囊只能强化说明，不能取代主证据区。

## 生成提示与失败条件

提示必须分别写清主框架和组件：

```text
主框架：H01；锁定商品区、标题区、证据区和阅读顺序。
可选组件：C02；直径约画布 22%，显示真实按扣微距，通过细线连接到右前角。
组件层级：第二焦点，不覆盖商品轮廓，不重复标题，不进入底部禁区。
```

出现以下任一情况即删除组件或返工：

- 卡片、圆窗或胶囊成为第一视觉主体。
- 平台合规主图出现任何 C01～C08 组件；营销首图实际组件超过 1 个、其他营销图超过 2 个，或出现未记录的同类组件形态。
- 策划写 `组件：NONE`，但成图实际出现任何组件形态；不得因它没有编号或不是计划内容而漏计。
- 组件没有证据，只放图标、口号或重复标题。
- 组件使用无可见或资料依据的空泛形容词充当事实，或无法对应具体部位、材料、结构、参数或可验证特征。
- 所有图片使用相同卡片位置和尺寸。
- 7/8/9 张套图中的组件图片数超过 4/5/6，或同一组件 ID 超过 2 次。
- 一张图超过 2 个组件，或卡片总面积明显超过 22%。
- 圆形细节窗未连接真实部位，材质卡无法对应源图。
- 组件遮挡商品结构、标题安全区或关键人物动作。
- 免责声明太小且画面仍会造成数量或包装误解；此时应改变画面本身。
- 把详解做成与主标题争夺层级的第二主标题，或每张图都复制相同“标题＋卡片＋说明”结构；套图少于 2 张 `component=NONE`、`evidence_dominant=true` 的营销图，或把平台干净主图计入该配额。
- 对比卡没有真实基准、同时改变多个变量、使用竞品 Logo，或通过故意降低另一侧光线和尺度制造优势。

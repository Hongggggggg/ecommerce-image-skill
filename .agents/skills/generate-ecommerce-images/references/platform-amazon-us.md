# Amazon US Listing 图片规则

本分支只用于 Amazon US Listing 的 MAIN 与 Secondary 图片。它不包含 Basic/Premium A+、视频、模特换装或自动上传。先完整读取 [平台通用规则与条件路由](platform-rules.md)，再应用本文件；未确认 Amazon US 时不得加载本分支。

## 政策核验记录

Amazon 政策和品类细则会变化。策划 Amazon US 发布候选前，必须在非像素记录中填写：

```text
amazon_category：
policy_source：
policy_checked_at：YYYY-MM-DD
policy_status：VERIFIED_CURRENT / UNVERIFIED
category_overrides：NONE / 具体规则
```

- `policy_source` 优先记录 Seller Central 当前 Product image requirements、对应商品类型或品类风格指南。
- 通用品类基线与具体品类规则冲突时，以当前具体品类规则为准。
- 发布候选的核验必须在本次制作或交付任务内完成；复用以前任务的核验记录时先标为 `UNVERIFIED`，重新检查后再更新日期与状态。
- 当前无法取得的字段仍须保留并写 `UNKNOWN`；这表示记录完整但没有取得发布资格，不能把字段删除或假装已核验。
- `policy_status=UNVERIFIED`、品类不明或来源无法核对时，可以继续制作设计预览，但不得标记为发布候选。
- 本文件中的数值是保守制作基线，不是永久政策；交付时不得把它们表述为 Amazon 永久保证。

官方核验入口：

- Seller Central Product image requirements：`https://sellercentral.amazon.com/help/hub/reference/G1881`
- Amazon Seller Forums 的 Amazon 回复可作为公开辅助说明，但不能替代账号后台与品类规则：`https://sellercentral.amazon.com/seller-forums/discussions/t/d5133ee0-5611-424d-8019-2dc74ce5befe`

## MAIN 保守基线

Amazon MAIN 是商品识别资产，不承担营销说服任务，也不参与营销框架三选一。策划卡固定使用 Amazon MAIN 平台网格，`T:NONE`、`E:NONE`、`组件：NONE`。`allowed_text_exact` 只列真实商品或包装本身必须保留的原生 Logo、标签和包装文字；没有原生文字时写 `NONE`，不得加入任何覆盖文字。

- 显示实际销售的准确 SKU、颜色、变体、数量、包装状态和随附部件；图片必须与商品标题和所选 ASIN 配置一致。
- 使用纯白背景，保守基线为 RGB `255/255/255`。
- 商品完整可见、清晰对焦、颜色准确，不裁掉关键部分。通用保守基线为商品占画面至少约 85%；具体品类另有规则时从其规定。
- 最长边至少 1000 px 作为通用缩放基线；当前项目 1024×1024 默认满足该下限，但仍须核验当前允许的最小/最大尺寸、文件大小、色彩模式和格式。
- 不添加标题、副标题、卖点、尺寸线、边框、色块、水印、插图、圆窗、信息卡、评级、徽章或其他营销图形。
- 不添加不属于实际商品的 Logo；商品本身原有 Logo、标签和包装文字必须与实物逐字一致。
- 不展示未包含的附件、可能被误认为随附的道具，或多视角拼贴；品类规则明确允许的例外必须写入 `category_overrides`。
- 需要实际商品专业照片的品类，不得用插画、模型凭空重建、概念渲染或占位图替代真实 SKU。

AI 整图规则仍然适用：允许以全部真实商品原图为身份参考，让图像模型一次生成完整 MAIN，或让图像模型对完整画面进行编辑；禁止抠图后脚本合成、单独补白底、外部修字和任何非生成式像素覆盖。若商品结构、比例、颜色、Logo、标签或包装被模型重绘且无法确认与实物一致，只能标为设计预览。以真实商品照片为身份主体且整图编辑后仍可核验一致时，才可在政策复核通过后进入发布候选。

## Secondary 图片

- Secondary 继续使用通用 7～9 张动态套图逻辑、说服链路、框架库、P/T/E、组件预算、文字覆盖和结构指纹；不得固定为 `MAIN + 5`。
- 每张图解决一个主要顾客问题，可用结构、动作、细节、尺度、尺寸、兼容、步骤、包装内容或真实场景提供证据。
- 使用方式、人体动作、尺度、性能、配件、结果和物理关系必须真实，不得制造不可能使用、危险操作、夸张效果或误导性前后对比。
- 包装内物品与情境道具必须视觉上可区分。道具有被误认为随附的风险时，优先移除；确有必要且当前规则允许时，使用清楚、可读、邻近的 `not included` 说明，并纳入 `allowed_text_exact` 与组件预算。
- 尺寸、包装数量、颜色、兼容清单、变体和销售配置必须与所选 ASIN 一致，且每条客户可见表述绑定 `claim_id`。
- 竞品名称、Logo、包装或可识别商业外观默认不出现；通用对比仍须公平、可测、有证据，并保持单变量、同尺度和同视角。
- 不生成或仿造 `Amazon's Choice`、`Best Seller`、星级图形、评论数量、排名、销量、奖项或 Amazon 风格徽章。只有当前政策允许且有可追溯实时依据时，才可另行评估；默认视为 `BLOCKED`。

## 美式文案与搜索词

- 客户可见文字使用自然、简洁、符合目标人群的美式英语，并采用已确认的美国常用单位；不得为了塞入关键词破坏语法、可读性或事实精度。
- 搜索词、长尾词和 Listing SEO 与图片内文案分开记录。烘焙在图片中的文字不等同于可索引 Listing SEO，不承诺带来排名提升。
- `CONDITIONAL` 声明所需限定词或免责声明必须与声明邻近并在移动端可读；无法容纳时删除该声明或将其标为 `BLOCKED`，不得缩成页脚小字。

## 高风险声明与品类升级

以下声明必须取得实际证据、保留原始适用范围，并完成当前 Amazon US 品类政策核验：

- 医疗、疾病、治疗、预防、诊断、疼痛、健康或身体功能。
- 化妆品暗示药物效果；食品、补充剂、成分、过敏原或营养。
- `FDA approved`、`clinically proven`、`doctor recommended`、`non-toxic`、`chemical-free`、`100% safe` 等权威、临床或绝对安全表述。
- 环保、可回收、生物降解、碳、节能或可持续性。
- 儿童/婴儿安全、防护装备、电气、电池、无线、农药、消毒或抗菌。
- 防水、承重、压力、速度、温度、容量、寿命、节省、兼容或其他绝对性能。
- 排名、销量、评论、奖项、背书、认证、测试、优越性比较、前后对比、模拟结果或用户证言。

证据至少记录来源主体、资料或文件、日期/年份、测试方法或适用条件、样本/使用背景、单位，以及必须相邻显示的限定词或免责声明。缺少证据时标为 `BLOCKED`；待补数值只可作为内部 `PLACEHOLDER`，不能进入图片。

补充剂、食品、化妆品、医疗器械、农药/消毒、儿童用品、防护装备、电气产品、电池、无线设备、汽车适配和环保/能源等品类属于升级检查范围。生成发布版文案前必须列出需要核验的法规、证据和 Amazon 品类规则；未完成时整套可继续作为设计预览，但不能给出发布候选结论。

## AI 视觉安全

- 不合成不存在的认证标志、评级、奖项、标签、测试读数、测量刻度、安全装备、附件或包装内容。
- 不让生成式人物暗示真实用户证言、医生/专家推荐、医疗身份或权威背书。
- 不生成可识别竞品商品用于对比，也不复制竞争品牌的商业外观。
- 每轮从最终像素检查商品结构、颜色、表面、端口、接缝、Logo、标签、数量、阴影、反射、人物手部与真实尺度；提示词声称“保持一致”不能替代观察。

## Amazon 发布资格检查

Amazon US 图片只有同时满足以下条件才可标为发布候选：

- `policy_status=VERIFIED_CURRENT`，且记录了站点、品类、来源、日期和适用的品类覆盖规则。
- MAIN 与 Secondary 角色没有混淆；MAIN 的文字、组件、道具和营销图形计数均为 0。
- SKU、颜色、数量、变体、包装与随附部件准确，商品身份可与真实原图核验。
- 所有客户可见事实都有 `claim_id`，没有 `PLACEHOLDER`、`BLOCKED` 或未满足条件的 `CONDITIONAL` 声明。
- 美式英语、单位、限定词和免责声明准确且在移动端可读。
- 没有 Amazon 徽章、评级、评论、伪认证、专家背书、可识别竞品或误导性道具。

任一项未通过时，按问题性质标为“设计预览，禁止直接发布”或“失败待返工”，不得用视觉评分抵消。

# 平台与发布规则

平台政策会更新。正式发布前必须以目标国家、平台后台、官方帮助页面和具体品类当时规则为准。本文件保存制作时采用的保守基线，不替代发布前核验。

## 三种首图角色

### Amazon MAIN

- 用途是平台合规商品识别，不承担广告封面任务。
- 使用纯白背景，完整、清晰地展示实际销售商品。
- 不添加营销文字、边框、水印、徽章、装饰图形或无关道具。
- 不展示包装中未包含的物品。
- 不用拼贴方式展示多个视角，除非具体品类规则明确允许。
- 商品身份、颜色、数量和销售变体必须与实际商品一致。

### TikTok Shop 干净首图

- 用途是商品卡中的快速、客观识别。
- 按目标市场和品类当时规则使用纯白或允许的干净背景。
- 完整展示实际销售商品，不添加误导促销信息、虚假折扣、平台仿冒标识或无关水印。
- 营销封面、多文字卖点图、尺寸图和步骤图默认放在后续图库，不自动作为第一张商品图。

### 营销首图 / 商品封面

- 是独立营销素材，不等同于 Amazon MAIN 或 TikTok Shop 干净首图。
- 默认用于后续图库、广告、社交封面或详情页首屏。
- 以一个主决策任务建立点击兴趣：快速识别商品，并理解一个已确认核心特性。
- 主标题必须明确包含消费者能立即理解的通用产品名称，优先采用“有依据的特性修饰词＋产品名称”。品牌名、系列名或纯口号不能替代产品名称。必须有一条价值说明，并有 1～2 组与可见证据绑定的 `label/detail`，至少一组完整配对；全部文字共同证明一个核心价值主张。
- 组件为 `0..1`：可使用一个小圆图、小卡片、规格芯片、状态标签、徽章、免责声明胶囊或微步骤条强化同一核心证据；直接标注的卖点标签和详细说明不要求装入组件。组件必须逐字纳入允许清单且不能取代主商品。
- 点击证据必须直接来自主商品、动作、结构、场景关系或与画面边缘相连的大尺度构图；从属组件只负责解释和强化。
- 能否作为平台第一张商品图，必须按目标市场、平台和品类当时规则单独判断。
- 不使用价格、虚假折扣、排名、倒计时、绝对化措辞或无依据性能图标。

Amazon MAIN 与要求无营销文字的 TikTok Shop 干净首图保持无文字。上述产品名称、价值说明、卖点标签和详细说明规则只适用于允许文字的营销首图/商品封面，不能据此把营销文字加到平台合规首图上。

## AI 图片与实际商品发布边界

分别判断“视觉是否通过”和“是否可发布”：

- AI 纯生成、商品身份被重绘、结构被重建或无法确认与实物一致的图片，必须在文件名、策划卡、执行清单和交付报告中标记为“设计预览，禁止直接发布”。
- `DESIGN PREVIEW`、`SIMULATED`、`NOT PUBLISHABLE`、`SIMULATED DIMENSIONS` 等发布状态默认不得烧进任何成图像素；模拟测试也只在非像素记录中披露。只有用户明确要求可见状态文字时才可例外，并须逐字纳入允许清单；它仍不计入商品信息文案覆盖。
- 平台干净主图和营销图都默认不显示发布资格水印或页脚；图片是否可发布只读取文件名、策划卡、执行清单与交付清单，不依赖画面小字。
- 以真实商品照片为主体、未重绘商品身份且只进行合规背景、光影或版式编辑的图片，可以进入发布候选。
- 平台或品类要求实际商品专业照片时，插画、数字渲染、纯生成效果图不能作为发布版 MAIN。
- 场景图和营销图即使视觉通过，也要检查是否错误暗示尺寸、材质、性能、配件或包装内容。
- 无法确认商品来源、实物一致性或平台资格时，不得标记为可直接发布。

## 输出规格

- 项目内部默认使用 1:1，不低于 1024×1024。
- 若目标平台或品类要求其他比例、更高分辨率、文件格式或数量限制，使用更严格要求。
- 每张图记录用途、目标平台或渠道、画幅、版本和发布资格。

## 发布资格

每张图标记为以下之一：

1. **发布候选**：视觉、事实和当前平台规则均通过，仍建议发布前在后台复核。
2. **设计预览，禁止直接发布**：适合确认创意或后续制作，但商品身份、AI来源或平台规则不满足发布要求。
3. **失败待返工**：存在商品、文字、尺寸、宣称、构图或平台错误。

商品身份、数量、文字、尺寸、宣称、实际照片资格和首图规则属于硬门槛；不能用构图美观或设计评分抵消。

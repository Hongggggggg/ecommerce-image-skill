# TikTok Shop 图片规则

本分支只用于 TikTok Shop 静态商品图片。先完整读取 [平台通用规则与条件路由](platform-rules.md)，再应用本文件；未确认 TikTok Shop 时不得加载本分支。具体站点和品类规则仍须在发布前以当前平台后台为准。

## TikTok Shop 干净首图

- 用途是商品卡中的快速、客观识别。
- 按目标市场和品类当时规则使用纯白或允许的干净背景。
- 完整展示实际销售商品，商品身份、颜色、数量、销售变体和包装内容必须准确。
- 不添加误导促销信息、虚假折扣、平台仿冒标识或无关水印。
- 目标站点或品类要求无营销文字时，固定使用 `T:NONE`、`E:NONE`、`组件：NONE`；`allowed_text_exact` 只列真实商品或包装本身必须保留的原生文字，没有原生文字时写 `NONE`，不得加入覆盖文字。
- 营销封面、多文字卖点图、尺寸图和步骤图默认放在后续图库，不自动作为第一张商品图。

TikTok Shop 干净首图不参与营销框架三选一，使用对应平台辅助网格。平台名称本身不构成霓虹、强光效、人物类型或促销化视觉的理由；具体风格继续读取通用本地化与视觉锁定规则。

## 发布检查

- 记录目标 TikTok Shop 站点、品类、核验来源和核验日期。
- 确认干净首图与营销首图没有混用，且首图背景、文字、组件、商品数量和销售配置符合当前站点/品类规则。
- 无法确认当前规则、商品身份或销售内容时，标为“设计预览，禁止直接发布”。
